---

## 🌟 Key Capabilities

- **⚡ Server Response (TTFB) Measurement:** Real-time millisecond diagnostics of Time-to-First-Byte to verify low-latency caching and CDN performance.
- **🔒 Socket-Level SSL/TLS Validation:** Inspects certificate issuer, expiration days, protocol version (TLS 1.3), and handshake integrity.
- **📱 Mobile-First Indexing Audit:** Validates meta viewport, tap target sizing, and responsive layouts.
- **🏷️ On-Page Semantic Hygiene:** Checks H1 single-tag discipline, title length, meta description quality, and canonical URL consistency.
- **📊 Schema.org JSON-LD Parsing:** Ensures full compliance with Google Rich Results (Organization, BreadcrumbList, WebApplication, FAQPage).

## 💻 Standalone Quick Start

Clone the repository and run the static web app instantly on any local server or GitHub Pages:

```bash
git clone https://github.com/mahmoudthabetmohamed-lgtm/seo-audit-engine.git
cd seo-audit-engine
# Open index.html in your browser or serve via Python:
python3 -m http.server 8080
```

Visit `http://localhost:8080` to access the interactive audit dashboard.
